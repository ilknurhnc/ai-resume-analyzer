# AI Resume ATS Analyzer

AI Resume ATS Analyzer is an end-to-end resume evaluation platform that analyzes PDF and DOCX resumes, calculates a rule-based ATS score, and generates AI-powered feedback using a locally hosted LLM through Ollama.

The project combines traditional software engineering practices with AI integration, Docker containerization, and modern backend architecture.

---

## Features

### Resume Upload

* Upload PDF or DOCX resumes
* Automatic text extraction
* File validation and error handling

### ATS Scoring Engine

The ATS score is generated by a custom rule-based scoring engine instead of relying on LLM-generated scores.

Evaluated categories:

* Readability
* Structure
* Experience Clarity
* Skills & Keywords
* Measurable Achievements
* Language Professionalism

### AI-Powered Resume Feedback

The application uses a local LLM running through Ollama to provide:

* Overall assessment
* Resume strengths
* Resume weaknesses
* ATS risks
* Actionable recommendations

### Interactive Dashboard

* ATS Score Card
* Score Label (Excellent / Good / Fair / Poor)
* Overall Assessment
* Top Recommendations
* Expandable Detailed Analysis

### Dockerized Architecture

* Backend container
* Frontend container
* Docker Compose orchestration
* Local Ollama integration

# ATS Scoring Logic

Unlike many AI-only resume analyzers, this project separates scoring from AI explanations.

## Score Generation

The ATS score is generated through a deterministic rule-based engine.

Example:

```text
Readability
Structure
Experience Clarity
Skills & Keywords
Measurable Achievements
Language Professionalism
```

This guarantees consistent scoring for identical resumes.

## AI Responsibilities

The LLM is responsible only for:

* Feedback generation
* Resume assessment
* Recommendations
* Strength/Weakness analysis

This architecture reduces hallucinations and improves reliability.
